# 🚗 Car Sales Analysis

## 📌 Project Overview
Car Sales Analysis is an end-to-end data analytics project designed to analyze car sales data and identify meaningful business insights.

The project uses Python, MySQL, and Power BI to clean, process, analyze, and visualize car sales data. It focuses on understanding sales performance, revenue generation, customer preferences, popular car brands, fuel types, and regional sales trends.

## 🎯 Project Objectives
- Analyze overall car sales performance.
- Identify the best-selling car brands and models.
- Understand fuel type and transmission preferences.
- Analyze region-wise sales performance.
- Calculate total revenue and average selling price.
- Identify premium-priced cars.
- Build an interactive Power BI dashboard.

## 🛠️ Tools & Technologies
- **Python:** Data cleaning and exploratory data analysis.
- **Pandas & NumPy:** Data manipulation and numerical analysis.
- **Matplotlib & Seaborn:** Data visualization.
- **MySQL:** Database management and SQL analysis.
- **Power BI:** Interactive dashboard development.
- **Jupyter Notebook:** Python development environment.

## 🔄 Project Workflow

### 1. Data Cleaning using Python
- Loaded the original dataset using Pandas.
- Checked missing values and duplicate records.
- Handled missing values.
- Removed duplicate records.
- Checked data types.
- Saved the cleaned dataset.

**Final Dataset:** 1,982 records and 12 columns.

### 2. Exploratory Data Analysis (EDA)
Performed analysis to understand:
- Brand-wise car sales.
- Average, maximum, and minimum selling prices.
- Fuel type distribution.
- Transmission distribution.
- Top 10 best-selling models.
- Region-wise sales.
- Brand-wise revenue.
- Average mileage by brand.
- Premium car analysis.
- Top 10 expensive cars.

### 3. Data Visualization
Created visualizations using Matplotlib and Seaborn:
- Bar charts.
- Pie charts.
- Histograms.
- Scatter plots.
- Correlation heatmap.
